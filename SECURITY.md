# Модель безопасности ServerPilot RU

## Принципы

1. **Credentials никогда не покидают устройство** без явного разрешения пользователя
2. **AI не получает секреты** — пароли и ключи не передаются в AI API
3. **AI-команды требуют ручного подтверждения** — нет автономного выполнения
4. **Опасные операции требуют явного подтверждения** с предупреждением
5. **Локальные данные зашифрованы** — AES-256-GCM с machine-specific ключом

## Хранение credentials

### Схема шифрования

```
Master Key = SHA-256(Windows MachineGUID + "ru.serverpilot.app.v1")
Nonce = random 96-bit (каждый раз новый)
Ciphertext = AES-256-GCM(Master Key, Nonce, plaintext)
Stored = base64(Nonce || Ciphertext)
```

### Что хранится зашифрованным

- SSH пароли (`server_credentials.credential_type = 'password'`)
- Passphrase для SSH ключей (`credential_type = 'passphrase'`)

### Что НЕ хранится

- Сами приватные ключи — только **путь к файлу** на диске
- AI API ключи — хранятся в `localStorage` браузера (WebView2), не в SQLite

### Что хранится открыто (не секрет)

- IP/хост сервера
- Порт
- Имя пользователя
- Путь к SSH ключу

## Классификация риска команд

| Уровень | Примеры | Действие UI |
|---|---|---|
| `read_only` | `df -h`, `ps aux`, `cat file` | Зелёная кнопка |
| `low` | `echo`, `pwd`, `ls` | Обычная кнопка |
| `medium` | `systemctl restart nginx`, `apt install` | Жёлтое предупреждение |
| `high` | `rm -r dir/`, `pkill process` | Оранжевое предупреждение |
| `critical` | `rm -rf /`, `mkfs`, `dd if=` | Красное предупреждение + требует подтверждения |

## Что AI НЕ может делать автоматически

- Удалять файлы
- Менять SSH конфигурацию
- Изменять firewall правила
- Создавать/удалять пользователей
- Перезагружать сервер
- Устанавливать пакеты
- Изменять права доступа

Любое из этих действий требует **явного клика** пользователя на кнопку "Выполнить".

## Аудит действий

Все выполненные команды записываются в локальную таблицу `audit_log`:

```
timestamp | server_id | action | command | success
```

В аудит **никогда не записываются**: пароли, ключи, API tokens.

## Безопасность SSH подключения

- Host key fingerprint показывается при первом подключении
- Проверка host key включена по умолчанию
- Поддержка known_hosts
- Keepalive для предотвращения разрыва
- Timeout при подключении (30 секунд)
- SSH private key остаётся на диске пользователя, не копируется в БД

## Сетевые подключения

Приложение устанавливает соединения только к:
1. **SSH серверам** — адреса, которые пользователь указал явно
2. **AI API endpoint** — URL, который пользователь указал в настройках (по умолчанию никуда)

Приложение **никогда не подключается** к серверам разработчика.
