## Критические проверки перед публичным релизом

1. **SmartScreen** — при запуске `.exe` Windows покажет предупреждение. Нужно проверить что пользователь может его обойти (кнопка «Подробнее» → «Выполнить»).
2. **Notifications** — `tauri-plugin-notification` без code signing может не доставлять уведомления в Action Center на Windows 11.
3. **SSH credentials** — после переустановки приложения credentials должны оставаться доступными (ключ шифрования выводится из Machine GUID — тест 21.1).
4. **PTY cleanup** — hanging SSH после закрытия (тест 23.1).
