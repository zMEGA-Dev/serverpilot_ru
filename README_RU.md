# ServerPilot RU

> **🧪 Beta-версия** — перед использованием прочитайте раздел [Предупреждение о Beta](#предупреждение-о-beta).

[English](README.md) | **Русский**

Локальное desktop-приложение для управления Linux и VPS серверами из Windows. ServerPilot RU подключается по SSH и предоставляет единый интерфейс для всего, что обычно требует терминала, файлового менеджера и веб-панели — без отправки учётных данных куда-либо.

---

## Что такое ServerPilot RU

ServerPilot RU — это desktop-приложение на базе [Tauri](https://tauri.app) (бэкенд на Rust, фронтенд на React), работающее полностью на вашей машине. Все учётные данные серверов хранятся локально, зашифрованные AES-256-GCM. Нет облачного аккаунта, нет телеметрии, нет обязательных внешних сервисов.

Основная аудитория — разработчики и системные администраторы, которые управляют одним или несколькими Linux/VPS серверами и хотят нормальный desktop-инструмент вместо браузерных панелей или разрозненных SSH-сессий.

## Основные возможности

### SSH / PTY / SFTP

- SSH-подключения с аутентификацией по паролю, ключевому файлу или SSH-агенту (Pageant, ssh-agent)
- Полноценный PTY-терминал с поддержкой нескольких вкладок — работает nano, vim, htop и другие интерактивные программы
- SFTP файловый менеджер с загрузкой, скачиванием, переименованием, удалением, chmod и встроенным редактором Monaco
- Учётные данные шифруются локально с помощью AES-256-GCM; никогда не записываются в логи и не передаются

### Главная (Dashboard)

Метрики сервера в реальном времени: CPU, RAM, диск, сеть, аптайм, средняя нагрузка, версия ядра, хостнейм. Цветовая индикация пороговых значений (жёлтый при 75%, красный при 90%). Исторические графики CPU, памяти и диска с обновлением каждые 10 секунд.

### Мониторинг

Отдельная страница мониторинга с настраиваемым интервалом обновления (3 / 5 / 10 / 30 секунд). Графики площадью для CPU + RAM совместно, отдельный график диска, график Load Average. Хранит до 720 точек данных (около часа при интервале 5 секунд).

### Логи

Просмотр логов для стандартных источников: syslog, auth.log, kern.log, nginx access/error, Apache2, MySQL, dmesg, dpkg.log, journald. Режим live tail с опросом каждые 3 секунды. Поиск с подсветкой совпадений. Классификация строк лога по уровню серьёзности (ошибка, предупреждение, инфо). Кнопка скачивания.

### Процессы

Полный список процессов через удалённый `ps`. Сортируемая таблица по PID, пользователю, CPU%, RAM%, состоянию, команде. Панель деталей. Отправка SIGTERM или SIGKILL с подтверждением. Защищённые PID (0, 1, sshd, init, systemd) — завершение sshd требует дополнительного предупреждения.

### PM2

Автоматическое обнаружение PM2. Установка одним кликом при отсутствии. Список с статусом, CPU, памятью, количеством перезапусков, аптаймом. Действия с приложениями: запуск, остановка, перезапуск, reload, удаление. Просмотр логов с поиском. Создание новых приложений с именем, скриптом, рабочей директорией, интерпретатором и аргументами. Переменные окружения отображаются с маскировкой секретов.

### Docker

Четыре вкладки: Контейнеры, Образы, Тома, Сети. Действия с контейнерами: запуск, остановка, перезапуск, приостановка, возобновление, удаление. Live-просмотр логов с поиском и хвостовым режимом. Загрузка и удаление образов. Удаление томов (с подтверждением потери данных). Инспекция сетей. Переменные окружения с маскировкой секретов. Авто-обновление.

### Git Deploy

Обнаружение существующих Git-репозиториев. Отображение статуса репозитория включая незафиксированные изменения. `git clone` и `git pull` с подтверждением перед pull при наличии незафиксированных изменений. История деплоев (последние 50 записей в localStorage). Desktop-уведомления при успехе и ошибке. Ярлык «Открыть в файлах».

### Nginx

Обнаружение установки Nginx. Список всех сайтов из `sites-available` и `conf.d`. Действия для каждого сайта: включить, отключить, удалить запись конфига (без удаления файла), перезагрузить Nginx, проверить конфиг. Встроенный редактор Monaco с поддержкой резервных копий и восстановления.

### SSL / Let's Encrypt

Встроенное управление SSL внутри раздела Nginx. Обнаружение Certbot. Отображение статуса сертификата, издателя, даты истечения и оставшихся дней. Получение новых сертификатов с вводом домена и email. Тестовый dry-run перед выпуском. Статус авто-продления. Desktop-уведомления при истечении и истёкших сертификатах.

### Аудит безопасности

Запуск аудита безопасности на стороне сервера через Rust-бэкенд. Результаты сгруппированы по категориям с индикатором оценки (0–100). Фильтрация по статусу: все / критические / предупреждения / пройдено / неизвестно. Анимированный прогресс сканирования. Быстрые исправления там, где применимо.

### Скрипты

Менеджер скриптов на SQLite. CRUD с именем, описанием, командой и поддержкой заполнителей `{{переменная}}` (запрашиваются при запуске). Автоматическая классификация риска по той же логике, что и в AI-ассистенте. История запусков для каждого скрипта. Переменные передаются на сторону Rust и разрешаются там — фронтенд никогда не строит shell-команды через конкатенацию.

### Резервные копии

Создание tar.gz-архивов на сервере через SSH, затем скачивание через SFTP. Проверка свободного места перед созданием. Диалог скачивания через Tauri fs plugin. Desktop-уведомление при ошибке. Фильтрация по серверу и статусу. История хранится в SQLite.

### Уведомления

Desktop-уведомления (нативные Windows) для: сервер недоступен, высокая загрузка CPU/RAM/диска, истечение/истечение SSL, ошибка backup, ошибка/успех деплоя. Настраиваемые пороги для каждой метрики. Anti-spam: CPU/RAM/Disk уведомляют только при первом превышении порога и снова только после возврата ниже порога.

### AI-ассистент (BYO API)

Подключается к любому OpenAI-compatible API: OpenAI, Ollama, LM Studio, vLLM или собственный сервер. Пошаговый режим диагностики — AI предлагает по одной команде за раз, вы оцениваете уровень риска и выбираете выполнить или пропустить. Безопасность: данные сервера (метрики, логи, вывод команд) всегда передаются отдельным user-сообщением с меткой `[ДАННЫЕ СЕРВЕРА]`, никогда в system prompt — это предотвращает prompt injection через содержимое логов. URL API валидируется (только http/https); API-ключи хранятся в `sessionStorage` (очищается при закрытии приложения; старые значения из `localStorage` мигрируются автоматически при первом запуске).

## Принципы безопасности

- **Учётные данные зашифрованы на диске** — AES-256-GCM с ключом, производным через SHA-256 для каждой установки
- **Нет shell injection** — все команды валидируются на стороне Rust; фронтенд не может создать произвольные shell-строки
- **Секреты не пишутся в логи** — пароли, ключи и токены никогда не попадают в файл логов
- **Защита от prompt injection** — данные сервера изолированы от system prompt AI
- **Нет обязательного облака** — приложение работает полностью офлайн; аккаунт или license server не требуются
- **Только локальное хранение** — `%LOCALAPPDATA%\ServerPilotRU\data.db` + `logs\app.log`; ничто не покидает вашу машину, кроме явно запускаемых AI-запросов

## Приватность / Local-first

ServerPilot RU не собирает данные об использовании, не отправляет аналитику и не требует аккаунта. Единственные исходящие сетевые соединения:

1. SSH-подключения к вашим собственным серверам
2. AI API вызовы — только когда вы явно их запускаете, на указанный вами endpoint

## Известные ограничения

- **Только Windows** — сборки для macOS и Linux возможны через Tauri, но пока не настроены
- **Большие файлы** (> 2 МБ) нельзя открыть во встроенном редакторе — скачайте и редактируйте локально
- **PTY терминал** открывает отдельное SSH-соединение для каждой вкладки
- Некоторые функции **Nginx/SSL** предполагают расположение файлов Debian/Ubuntu
- **KDF** использует SHA-256(MachineGUID + AppID); усиление до PBKDF2/Argon2id запланировано на стабильную версию
- **Pinning SSH host-key** пока не реализован (fingerprint показывается, но не сохраняется/проверяется)

## Предупреждение о Beta

> **ServerPilot RU — это Beta-релиз.** Он предназначен для тестирования и оценки. Приложение стабильно для повседневного использования, но неожиданные проблемы всё ещё возможны. Всегда держите независимые резервные копии всего важного.
