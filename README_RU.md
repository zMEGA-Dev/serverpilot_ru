# ServerPilot RU

> 🚧 **Alpha-версия** — ServerPilot RU находится на этапе активного тестирования. Перед использованием прочитайте [Предупреждение об Alpha](#предупреждение-об-alpha).

[English](README.md) | **Русский**

Локальное Windows-приложение для управления Linux/VPS-серверами по SSH. ServerPilot RU объединяет терминал, SFTP, мониторинг, логи, Docker, PM2, Git Deploy, Nginx, SSL, аудит безопасности, скрипты, уведомления и необязательный AI в одном desktop-интерфейсе.

> **ServerPilot RU создан при моральной и финансовой поддержке [SerpMax](https://serpmax.ru) и [Vibes](https://vibes.su).**

---

## Что такое ServerPilot RU

ServerPilot RU — desktop-приложение для Windows на базе [Tauri 2](https://tauri.app), Rust, React, TypeScript и WebView2.

Приложение построено по принципу local-first:

- подключения к серверам выполняются напрямую с компьютера пользователя по SSH;
- данные серверов хранятся локально;
- SSH-пароли и passphrase для ключей шифруются локально с помощью AES-256-GCM;
- обязательного облачного аккаунта ServerPilot нет;
- обязательная телеметрия и аналитика отсутствуют;
- AI является необязательным и использует endpoint, который указывает пользователь.

Основная аудитория — разработчики и системные администраторы, управляющие Linux/VPS-серверами.

## Основные возможности

### SSH / PTY / SFTP

- SSH-аутентификация по паролю, приватному ключу или SSH-agent
- Работа с fingerprint и keepalive
- Полноценный PTY-терминал с несколькими вкладками
- Поддержка интерактивных программ `bash`, `vim`, `nano`, `htop`, `top` и других
- SFTP-файловый менеджер: просмотр, загрузка, скачивание, переименование, удаление и редактирование файлов
- Встроенный редактор Monaco для поддерживаемых текстовых файлов
- Локальное шифрование SSH-паролей и passphrase

### Dashboard

- CPU, RAM, диск, сеть, uptime и Load Average
- ОС, ядро, hostname, IP и пользователь
- История показателей и графики

### Monitoring

- Настраиваемый интервал обновления
- Графики CPU, RAM, диска и нагрузки
- Локальная история показателей

### Logs

- syslog, auth, kernel, Nginx, Apache, MySQL, dmesg, dpkg и journald
- Поиск и подсветка совпадений
- Классификация строк по уровню
- Live tail
- Скачивание логов

### Processes

- Список процессов сервера
- PID, пользователь, CPU, RAM, состояние и команда
- Сортировка и поиск
- Детали процесса
- SIGTERM / SIGKILL с подтверждением и защитой системных PID

### PM2

- Обнаружение и установка PM2
- Статус, CPU, RAM, количество перезапусков и uptime
- Запуск, остановка, перезапуск, reload и удаление
- Просмотр логов
- Запуск приложений
- Маскировка секретов в переменных окружения

### Docker

- Контейнеры, образы, тома и сети
- Запуск, остановка, перезапуск, pause, unpause и удаление
- Логи и live tail
- Загрузка и удаление образов
- Информация о контейнерах и сетях
- Маскировка секретов в переменных окружения

### Git Deploy

- Обнаружение Git
- Clone и Pull
- Работа с веткой и директорией
- Статус репозитория и текущий commit
- Предупреждение о незакоммиченных изменениях
- Локальная история деплоев

### Nginx

- Обнаружение и статус Nginx
- Проверка конфигурации через `nginx -t`
- Поиск сайтов
- Enable / Disable / удаление записи конфигурации
- Встроенный редактор Monaco
- Резервные копии конфигураций перед изменением
- Проверка конфигурации перед reload

### SSL / Let's Encrypt

- Обнаружение Certbot
- Статус сертификата, издатель, срок действия и оставшиеся дни
- Получение сертификатов
- Проверка конфигурации Nginx перед reload
- Статус продления и dry-run
- Фильтрация вывода приватных ключей

### Аудит безопасности

Read-only проверка сервера:

- SSH
- firewall
- открытые/listening порты
- неудачные входы
- доступные средства безопасности

Результаты классифицируются как **pass / warning / critical / unknown**. Аудит не изменяет конфигурацию сервера.

### Скрипты

- Менеджер скриптов на SQLite
- Переменные `{{name}}`
- Автоматическая оценка риска
- Подтверждение опасных команд
- История запусков
- Получение команды по `script_id`
- Валидация на стороне Rust
- Ограничение вывода

### Резервные копии

- Создание удалённых `tar.gz`
- Проверка свободного места
- Скачивание через SFTP
- История операций

> **Важно для Alpha:** Backup Manager ещё находится в зоне ручного тестирования. Он не заменяет независимую резервную стратегию для production-серверов.

### Уведомления

Поддерживаются уведомления Windows о таких событиях, как:

- сервер недоступен;
- высокая загрузка CPU/RAM/диска;
- истечение SSL;
- успешный/неуспешный deploy;
- ошибка backup.

В текущей Alpha проверка уведомлений зависит от запущенного приложения; отдельного фонового daemon нет.

### AI-ассистент (BYO API)

Необязательный AI для OpenAI-compatible endpoints, включая OpenAI, Ollama, LM Studio, vLLM и собственные серверы пользователя.

AI может:

- собирать выбранный контекст сервера;
- предлагать диагностические команды по одной;
- оценивать риск;
- ждать явного подтверждения пользователя перед выполнением.

AI не нужен для основных функций управления сервером.

## Принципы безопасности

- **Local-first:** обязательного облачного сервиса ServerPilot нет.
- **Шифрование credentials:** SSH-пароли и passphrase ключей шифруются локально AES-256-GCM.
- **Явное выполнение команд:** опасные операции требуют подтверждения пользователя.
- **Read-only Security Audit:** аудит не изменяет настройки сервера.
- **Фильтрация секретов:** чувствительные значения скрываются там, где это предусмотрено.
- **Защита AI:** данные сервера отделены от system prompt.
- **Нет захардкоженных AI API keys:** ключи задаёт сам пользователь.

> Заявления безопасности относятся к текущей Alpha-реализации и не означают невозможность взлома или ошибок.

## Приватность и сетевые подключения

ServerPilot RU не требует аккаунта и не использует обязательную аналитику.

В обычной работе приложение может подключаться к:

1. Linux/VPS-серверам, которые явно указал пользователь, прежде всего по SSH/SFTP.
2. AI endpoint, который пользователь указал в настройках, при использовании AI.
3. Внешним ссылкам, которые пользователь сам открывает из приложения.

SSH-credentials используются для аутентификации на выбранном пользователем сервере и не отправляются на сервер ServerPilot.

## Предупреждение об Alpha

> **ServerPilot RU — Alpha-релиз.** Программа предоставляется для тестирования и оценки. Функции могут изменяться, форматы данных могут меняться между Alpha-версиями, возможны неожиданные ошибки.

## Известные ограничения

- Только Windows desktop-версия
- Основная тема сейчас тёмная
- Большие файлы сверх лимита редактора нужно скачивать и редактировать отдельно
- Каждая вкладка PTY использует отдельное SSH-соединение
- Некоторые Nginx/SSL-сценарии рассчитаны на распространённую структуру Debian/Ubuntu
- Проверка уведомлений требует запущенного приложения
- Некоторые длительные SSH-операции ещё требуют дополнительного runtime-тестирования
